# NukeRat API

The NukeRat ecosystem has two types of APIs:

1. **Implant API**: used by implants to communicate with the server.
2. **Team server API**: used by the NukeRat client to manage the server and implants.

## Examples

For demonstration purposes, you can find a minimal example of API usage in the `api.py` file.

# Documentation

Complete documentation for all routes, including schemas, is available at: [https://nukerat.com/docs/api/](https://nukerat.com/docs/api/).
